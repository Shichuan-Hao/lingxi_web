# AssistGen 项目说明文档

## 一、项目简介

AssistGen 是一个 AI 对话平台前端项目，提供两大核心功能模块：

- **AI 对话主界面**：支持流式对话、深度思考（展示推理过程）、联网搜索、知识库问答（RAG）、多会话管理。
- **电商客服界面**：独立的电商场景页面，支持商品展示、客服聊天、图片上传。

后端对接 Python 服务（推测为 FastAPI），通过 SSE 实现流式响应。

## 二、技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Vue 3 (Composition API + `<script setup>`) |
| 语言 | TypeScript |
| 构建工具 | Vite 5 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| HTTP 请求 | Axios（部分认证接口）+ Fetch（流式对话） |
| Markdown 渲染 | markdown-it + marked |
| 安全 | DOMPurify（XSS 防护）、SHA-256（前端密码哈希） |

## 四、核心模块说明

### 4.1 路由设计

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | Login.vue | 登录/注册入口，未登录时重定向至此 |
| `/chat` | Home.vue | AI 对话主页面（需登录） |
| `/ecommerce` | EcommerceService.vue | 电商客服页面 |

路由守卫在 `src/router/index.ts` 中实现，未登录用户访问 `/chat` 会自动跳转到 `/`。

### 4.2 数据流

```
用户操作 → View 组件
              │
              ▼
         Pinia Store（状态管理）
              │
              ▼
      services/api.ts（ApiService / AuthService）
              │
              ▼
   fetch(SSE流式) 或 axios(REST)
              │
              ▼
       后端 API (localhost:8000)
```

### 4.3 AI 对话流程（Home.vue）

1. 用户在输入框输入文本（可附带文件上传）
2. 构建消息列表，调用 `ApiService.chat()` / `reason()` / `search()`
3. 通过 Fetch API 以 SSE（Server-Sent Events）方式流式接收后端响应
4. 实时更新聊天区域内容，Markdown 渲染 + DOMPurify 净化
5. 会话自动保存到后端，可通过侧边栏切换历史会话

### 4.4 三大对话模式

| 模式 | 方法 | 对应后端端点 | 说明 |
|------|------|-------------|------|
| 普通对话 | `ApiService.chat()` | `/api/chat` | 基础对话模式 |
| 深度思考 | `ApiService.reason()` | `/api/reason` | 展示 AI 推理过程，消息分 `thinking` 和 `answer` 两部分 |
| 联网搜索 | `ApiService.search()` | `/api/search` | 返回结构化搜索结果，含标题/URL/摘要 |

### 4.5 认证机制

- JWT Token 存储在 localStorage（key: `token`）
- 登录成功后 Axios 拦截器自动在所有请求头中添加 `Authorization: Bearer <token>`
- 401 响应时自动清除 Token 并跳转登录页
- 前端密码使用 SHA-256 哈希后再发送

### 4.6 后端 API 端点汇总

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/chat` | POST | 流式对话 |
| `/api/reason` | POST | 流式推理（深度思考） |
| `/api/search` | POST | 联网搜索 |
| `/api/conversations` | GET/POST | 会话列表/创建 |
| `/api/conversations/{id}` | PUT/DELETE | 重命名/删除会话 |
| `/api/conversations/{id}/messages` | GET | 获取会话消息 |
| `/api/conversations/{id}/clear` | DELETE | 清空会话消息 |
| `/api/register` | POST | 用户注册 |
| `/api/token` | POST | 登录获取Token |
| `/api/users/me` | GET | 获取当前用户信息 |
| `/api/langgraph/query` | POST | LangGraph 工作流查询 |
| `/api/upload` | POST | 文件上传 |

## 五、如何运行项目

### 5.1 环境要求

- **Node.js** >= 18（推荐 20 LTS）
- **npm** >= 9

### 5.2 安装依赖

在项目根目录执行：

```bash
npm install
```

### 5.3 启动开发服务器

```bash
npm run dev
```

启动后，终端会显示本地访问地址（默认为 `http://localhost:5173`）。

### 5.4 代理配置说明

`vite.config.ts` 中配置了代理规则：

```ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8000',  // 后端地址
      changeOrigin: true,
    }
  }
}
```

即前端请求以 `/api` 开头的接口，Vite 开发服务器会自动转发到 `http://localhost:8000`。

### 5.5 启动后端

要完整使用项目功能，需要同时启动后端服务。请确保后端服务运行在 `http://localhost:8000`。

## 七、打包与部署

### 7.1 打包命令

```bash
npm run build
```

构建成功后，产物输出到 `dist/` 目录，典型输出如下：

| 文件 | 大小 | 说明 |
|------|------|------|
| `dist/index.html` | 0.46 kB | 入口 HTML |
| `dist/assets/index-*.css` | ~61 kB | 样式文件 |
| `dist/assets/index-*.js` | ~303 kB | 业务逻辑 |

### 7.2 本地预览打包产物

```bash
npm run preview
```

Vite 会在本地启动静态服务器预览 `dist/` 目录，用于在部署前验证打包结果。

### 7.3 部署到服务器

将 `dist/` 目录下的所有文件上传到服务器的 Web 静态目录即可。

**Nginx 配置示例**：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/lingxi_web/dist;
    index index.html;

    # SPA 路由：所有页面请求返回 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理到后端
    location /api/ {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        
        # SSE 流式响应支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
```

**关键说明**：
- `try_files $uri $uri/ /index.html` 是必须的，因为 Vue Router 使用 History 模式，所有路径都由前端路由处理。
- `proxy_buffering off` 确保 SSE 流式对话不被 Nginx 缓冲。
- 后端 API 必须运行在 `http://localhost:8000`（或修改 proxy_pass 指向实际后端地址）。

## 八、关键注意事项

1. **后端依赖**：本项目为纯前端项目，所有 AI 功能依赖后端 API，请确保后端服务已启动。
2. **登录流程**：首次使用需先注册账号（邮箱 + 密码），登录后 Token 保存在浏览器 localStorage。
3. **流式响应**：对话采用 SSE 流式传输，需要后端支持该协议。
4. **主题切换**：支持暗色/亮色模式，切换状态保存在 localStorage。
